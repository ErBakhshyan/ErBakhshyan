# Erik Bakhshyan

Frontend Engineer from Armenia

Four years of commercial experience building production web applications
end to end. I work primarily with React, Next.js and TypeScript, and I
tend to take on the harder parts of a build - application architecture,
e-commerce logic, headless CMS setup - rather than the interface layer
alone.

Over the past two years my focus has been AI-powered product features on
top of the OpenAI API: prompt design, structured output parsed into the
UI, and the error handling, rate limiting and edge cases that separate a
demo from something a business runs on.
